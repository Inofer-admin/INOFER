# INOFER

Sistema de planta de INOFER: tablero de utilización de inyectoras, órdenes de producción,
base de piezas y moldes, plan Gantt e IA de planta.

- **Web / celular:** https://inofer-admin.github.io/INOFER/ (instalable como app)
- **PC (Windows):** [INOFER.jar](https://inofer-admin.github.io/INOFER/INOFER.jar). Hacer doble clic y elegir "Sí" para instalar.

La app se actualiza sola: cada vez que se publica un cambio en este repositorio,
las PC y los celulares toman la versión nueva al abrir INOFER (o tocando "Actualizar ahora").
Los datos de la planta NO están acá: están en la planilla de Google conectada con "Activar Tiempo Real".
